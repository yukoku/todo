# TODO

ブラウザで動くシンプルな TODO アプリです。依存パッケージはなく、Node.js だけで起動・テストできます。

## 機能

- タスクの追加・完了切り替え・編集・削除
- すべて完了にする / すべて未完了に戻す
- 「すべて / 未完了 / 完了済み」での絞り込み（URL のハッシュに反映されるので、リロードしても維持されます）
- 完了済みタスクの一括削除
- localStorage への自動保存（同じブラウザの別タブとも同期）
- ライト / ダークモード、スマートフォン表示、キーボード操作、日本語入力（IME）に対応

## 起動

Node.js 20 以上が必要です。

```sh
npm start
```

ブラウザで http://127.0.0.1:3000 を開きます。ポートは `PORT=8080 npm start` のように変更できます。

> ES Modules を使っているため、`src/index.html` をファイルとして直接開いても動きません。`npm start` で起動してください。

## 操作

| 操作 | 方法 |
| --- | --- |
| 追加 | 入力欄に入力して Enter、または「追加」ボタン |
| 完了 / 未完了 | 各タスク左のチェックボックス |
| 編集 | タスク名をダブルクリック、または鉛筆アイコン。Enter で確定、Esc で取り消し。空にして確定すると削除 |
| 削除 | ゴミ箱アイコン |
| すべて完了 | 入力欄左のチェックボックス |

## テスト

```sh
npm test
```

## 構成

```
src/
  index.html   画面の HTML
  styles.css   スタイル
  app.js       画面の描画とイベント処理
  todos.js     TODO リストを操作する純粋関数
  storage.js   localStorage への保存・読み込み
test/          node:test によるユニットテスト
server.js      開発用の静的ファイルサーバー（src/ だけを配信）
```
